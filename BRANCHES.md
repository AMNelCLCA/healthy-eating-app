# Branches

- `phone`: the iPhone version. Served at https://amnelclca.github.io/healthy-eating-app/
- `laptop`: the laptop version. Served at https://amnelclca.github.io/healthy-eating-app/laptop/
- `main`: what GitHub Pages publishes. It is the `phone` branch at the root plus a copy of the `laptop` branch in `laptop/`.
  Don't edit `main` directly: change `phone` or `laptop`, then rebuild `main` from them.

Both versions use the same saved-data format, so a backup exported from one imports into the other.
